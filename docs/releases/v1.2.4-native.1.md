# KataKecil — Native Preview 1

Penyelarasan pertama dengan web 1.2.3: font UI sistem, header Library/Settings, proporsi sampul, permukaan tombol/kaca dan susunan Settings. Advanced kembali berbentuk accordion, dengan About dan updater di dalamnya. Logo loading menggunakan aset yang sama.

Android31+ memakai blur pada sampel latar panel; teks tetap tajam. Android lama menggunakan fallback warna. Perubahan Reader dan Publisher yang lebih rinci dilanjutkan pada preview berikutnya.

Unduh **KataKecil.apk**. Nama launcher tetap **KataKecil**, package `id.karisyono.katakecil.nativeapp`, versionCode12, kunci Karisyono yang sama. Pasang di atas APK native sebelumnya tanpa uninstall. APK Capacitor tetap terpisah; data native dipertahankan.

**QA perangkat oleh pemilik.** Build, identitas paket, tanda tangan, alignment dan checksum diperiksa; tidak menjalankan suite QA atau emulator. Coba Library, Settings, tema terang/gelap, Advanced, dan dialog Liquid Glass. Ini preview native tersendiri, bukan pembaruan web/Capacitor.
