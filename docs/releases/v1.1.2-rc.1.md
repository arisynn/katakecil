# KataKecil 1.1.2-rc.1 — Build uji

**Pembaruan laporan:** pemilik mengonfirmasi Play Protect juga memblokir build ini saat dibuka dari unduhan GitHub. Perbaikan visual tidak menyelesaikan blokir. Pengajuan peninjauan Google sudah diterima, tetapi belum ada keputusan pencabutan blokir. Hentikan pemasangan; jangan melewati Play Protect. [Pemeriksaan lanjutan](../play-protect-review.md).

- Sampul Library di mode gelap tidak lagi memiliki bayangan pada kotak gambar yang terlihat seperti bingkai. Ukuran dan rasio sampul tetap.
- Perbaikan CSS yang sudah live di web kini disertakan dalam aset APK.
- Pesan verifikasi updater menyebut pemeriksaan tanda tangan/checksum secara spesifik; hasil ini bukan penilaian keamanan malware dari Google.
- Mempertahankan perbaikan splash, tema System, panel updater dan loading pagination dari 1.1.1.

**Play Protect belum terselesaikan.** Pemilik mengonfirmasi peringatan “Aplikasi berbahaya diblokir” saat memasang 1.1.1. Pemeriksaan awal belum menjelaskan penyebabnya. Build ini bukan klaim perbaikan klasifikasi atau bukti bebas malware. Jangan melewati atau menonaktifkan Play Protect; jika masih diblokir, hentikan pemasangan.

Identitas tetap `id.karisyono.katakecil`, penanda tangan Karisyono, versionCode6. Tidak mengganti package, sertifikat, izin, dependensi atau alur installer untuk menghindari deteksi. Rilis kandidat tidak ditawarkan sebagai pembaruan stable otomatis. Data aplikasi dipertahankan pada pembaruan normal tanpa uninstall.

Pemeriksaan terbatas: `npm audit --omit=dev` melaporkan nol kerentanan runtime yang dikenal; build web/Android, tanda tangan, alignment dan checksum diperiksa. Audit npm bukan pemindaian malware. Tidak ada QA browser/HP, pengulangan suite tes, pengunggahan APK ke layanan pemindai atau pengajuan ke Google. QA lanjutan ditangani pemilik.

Untuk laporan pemilik: sebutkan hasil pemasangan dan apakah peringatan yang sama muncul, tanpa memaksa pemasangan jika diblokir. Jika terpasang tanpa blokir, periksa sampul mode gelap. Hilangnya peringatan pada satu perangkat pun belum membuktikan penyebab sebelumnya atau keamanan menyeluruh.
