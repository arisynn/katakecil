# KataKecil 1.2.3 Stable

Pengaturan Liquid Glass dan ambient glow kini tersedia dalam APK. Package `id.karisyono.katakecil`, versionCode **11**, memakai sertifikat Karisyono yang sama agar dapat dipasang sebagai pembaruan di atas versi sebelumnya.

## Perubahan sejak APK 1.2.1

- Karusel Library memakai sampul utuh berlapis dan panggung dua kolom pada desktop dari pembaruan source 1.2.2.
- Pengaturan **Liquid Glass** menyediakan kebeningan 0–100% (default **75%**), blur 0–40 px (default **20 px**) dan Ambient glow 0–100% (default **60%**), dengan pratinjau langsung dan reset bersama.
- Ambient statis mengikuti warna aksen UI; intensitas 0 mematikannya. Glow lokal sampul tetap mengikuti warna buku.
- UI terang memakai Pearl dan UI gelap memakai charcoal. Warna kertas serta teks buku tetap seperti sebelumnya; naskah tetap opak tanpa gradasi ambient.
- Sheet tiga slider dipadatkan untuk layar pendek dan landscape. Pengaturan disimpan antarsesi/antartab, disertakan dalam backup, dan dipertahankan saat reset kenyamanan teks.
- Loading wordmark lama, efek tekan, swipe karusel dan posisi baca tetap menggunakan implementasi yang sudah ada.

## Pemeriksaan

- Build helper web, typecheck dan pemeriksaan sintaks/modul lulus.
- Pemeriksaan web sebelumnya: 31 tes terarah dan Chromium dengan katalog/episode mock, termasuk ambient mati/maksimum, aksen, tema terang/gelap, slider tanpa scroll, swipe dan pelestarian posisi baca. [Hasil](https://github.com/arisynn/katakecil/blob/main/docs/generated/ambient-glow-web.json).
- Saat persiapan APK, 12 tes terarah updater dan preferensi kaca lulus. Build memakai `--skip-qa`, tanpa mengulang suite penuh, lint Android, emulator atau HP fisik.
- APK diperiksa untuk signature v2/v3, sertifikat Karisyono, alignment, package/versi, checksum dan kesamaan aset web. [Bukti artefak](https://github.com/arisynn/katakecil/blob/main/docs/generated/1.2.3-stable-validation.json).

## Unduhan dan uji singkat di HP

Unduh `KataKecil-1.2.3-Karisyono.apk` dari Assets, atau periksa pembaruan melalui **Pengaturan → Pembaruan aplikasi**. Berkas `.sha256` dan `KataKecil-release-info.json` menyertakan checksum serta revisi source.

1. Pasang di atas APK lama dan periksa progres, catatan serta EPUB lokal.
2. Buka **Pengaturan → Liquid Glass**, coba ambient 0/60/100%, ganti aksen/tema, lalu tutup dan buka ulang aplikasi.
3. Coba ketiga slider serta reset 75% / 20 px / 60%, termasuk saat layar landscape.
4. Buka buku, pastikan naskah tetap polos dan posisi baca sama; coba swipe karusel dan RSVP.
