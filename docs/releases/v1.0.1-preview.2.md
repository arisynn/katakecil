# KataKecil v1.0.1-preview.2

Versi aplikasi **1.0.1-preview.2**, versionCode **2**. Package tetap `id.karisyono.katakecil`.

## Unduh dan pasang

- [APK Karisyono](https://github.com/arisynn/katakecil/releases/download/v1.0.1-preview.2/KataKecil-1.0.1-preview.2-Karisyono.apk)
- [Semua aset rilis](https://github.com/arisynn/katakecil/releases/tag/v1.0.1-preview.2)

Pasang APK baru di atas versi lama; jangan uninstall atau menghapus data. Preview 1 belum memiliki updater sehingga pemasangan Preview 2 ini perlu dilakukan satu kali secara manual. Setelahnya gunakan **Settings → App → App updates**.

Android meminta konfirmasi instalasi. Jika diminta izin pemasangan dari KataKecil, izinkan melalui halaman Android yang dibuka, kembali ke aplikasi lalu ketuk **Install update** lagi. Membatalkan installer tidak menghapus aplikasi lama. Build debug atau APK dengan sertifikat berbeda tidak dapat memperbarui rilis Karisyono langsung.

## Perubahan

- Efek kaca global yang diadaptasi dari `kaca.css` pemilik proyek: panel, tombol, toolbar, bottom sheet, picker dan preview slider.
- Lensa tab yang bergerak mengikuti tombol aktif tanpa menggandakan label; sheet, header dan tab tetap terpasang ketika berpindah panel buku/tampilan.
- Tema dan aksen global tetap berlaku; kontras label aktif ditangani, Custom mempertahankan bidang panel yang solid, reduced motion dan fallback blur/mask tersedia.
- Pemeriksaan GitHub Releases otomatis paling sering sekali sehari setelah pemeriksaan berhasil, serta pemeriksaan manual. Rilis Preview ikut diperiksa pada build Preview; build stabil menyaring prerelease.
- Unduh, progres, pembatalan, verifikasi APK dan pembukaan installer Android dari aplikasi. Tidak ada token GitHub di APK, akun baru atau pengiriman isi buku.
- Versi build terpusat di `app-version.json`, nama APK/checksum/metadata mengikuti versi; unit test native menjadi bagian build release.

## Hasil dan batas pengujian

Baseline setelah pull: **63 tes lulus**. Suite akhir: **69 tes web lulus**; setelah penyempurnaan terakhir, **14 tes terarah lulus**. **3 unit test Android lulus**. Build, typecheck, check, assembleRelease, lintRelease dan verifikasi signing/alignment lulus. Lint masih memuat peringatan toolchain/resource/icon yang tercatat di laporan build.

Chromium menjalankan Reader asli dengan EPUB Alice domain publik, Settings/popup tema, 18 pemeriksaan posisi lensa dan 120 kombinasi preview slider pada enam lebar layar serta tema terang/gelap. Tidak ada exception JavaScript pada skenario app tersebut.

**Tetap Preview:** belum diuji pada emulator/HP fisik. Alur izin installer, upgrade nyata sambil mempertahankan data, TTS perangkat, notch/IME dan performa ponsel rendah perlu QA perangkat. Pengujian browser bukan bukti instalasi Android. Rilis source/APK ini tidak memublikasikan situs atau melakukan migrasi/deployment Supabase.
