# KataKecil 1.0.0 — Android Preview

Rilis APK Android pertama untuk mencoba KataKecil di HP, dengan logo yang sudah ada dan sertifikat **Karisyono**. Tag GitHub `v1.0.0-preview.1`; versi aplikasi Android `1.0.0`, build `1`.

**Status: Preview.** APK sudah melewati build, lint, dan pemeriksaan tanda tangan. Uji di HP fisik/emulator belum dilakukan, sehingga perilaku gesture, keyboard, file picker, dan suara perangkat masih perlu dicoba.

## Memasang

1. Gunakan Android **7.0 / API 24+** dan Android System WebView **113+**.
2. Unduh APK, buka berkas, lalu ikuti petunjuk pemasangan Android.
3. Buka Library dan pilih buku, atau impor EPUB sendiri melalui **Settings → Advanced → Import an EPUB**.

Untuk pembaruan, pertahankan aplikasi lama dan gunakan APK dengan kunci yang sama. Jika beralih dari instalasi debug atau tanda tangan berbeda, simpan backup dahulu sebelum mengganti instalasi.

## Yang tersedia

- Reader halaman/scroll dengan pengaturan huruf, spasi, tema, dan posisi baca.
- Highlight, catatan, bookmark, pencarian episode, kamus, dan terjemahan teks pilihan.
- Android TextToSpeech dengan pilihan bahasa/suara yang terpasang, play/pause/resume, kecepatan, dan penanda kata sesuai dukungan mesin suara.
- Navigasi Back, layar penuh, area aman layar, orientasi, serta opsi layar tetap menyala.
- Impor EPUB lokal hingga **30 MB** dan pemilih lokasi simpan untuk ekspor/backup.
- Backup/pemulihan progres, anotasi, bookmark, dan pengaturan melalui JSON hingga **8 MB**.
- Perbaikan navigasi, penyimpanan progres, backup, dan dialog mobile yang juga masuk ke source web.

## Data dan koneksi

EPUB impor pribadi bisa dibaca offline. Buku server tetap memerlukan pemeriksaan publikasi online saat dibuka. Backup JSON membawa metadata bacaan dan pengaturan; EPUB perlu diimpor ulang. Browser dan APK memiliki penyimpanan terpisah dan belum menyinkronkan data lewat akun.

Baca nyaring dijeda saat aplikasi ditinggalkan. Suara offline bergantung pada paket suara Android; suara online, kamus, dan terjemahan memerlukan layanan jaringan terkait.
