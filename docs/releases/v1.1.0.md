# KataKecil 1.1.0 Official

- Pembacaan tanpa login; satu episode utuh dimuat ketika dibuka. Tidak melakukan prefetch seluruh buku.
- Pemeriksaan publikasi/revisi dan kuota terpusat untuk volume teks, episode berbeda, serta permintaan serentak. Jalur EPUB publik lama dan akses naskah langsung ditutup; unduhan Publisher terotorisasi tetap tersedia.
- Splash Android bergelombang/fade, latar mengikuti tema tersimpan dan logo splash menggunakan accent.
- Resume, highlight, notes, arc, pagination dan TTS tetap tersedia. Nomor halaman dan pencarian berlaku per episode.

Pasang **KataKecil-1.1.0-Karisyono.apk** di atas versi lama tanpa uninstall. Package `id.karisyono.katakecil`, versionCode4, signer Karisyono yang sama. Updater memeriksa GitHub Releases dan memverifikasi APK sebelum membuka pemasang Android; instalasi tetap memerlukan konfirmasi Android.

Rilis official atas persetujuan pengguna setelah pengecekan Android. QA lanjutan rilis ini ditangani pengguna; suite QA/browser/HP tidak diulang. Build release, signature v2/v3, alignment dan checksum diverifikasi. QA sebelumnya tercatat pada laporan keamanan; hasil tersebut tidak diklaim sebagai QA splash baru. Tidak dirilis melalui Play Store.

Buku, UUID episode dan jadwal publikasi dipertahankan. Teks episode yang sudah diterima tetap bisa direkam/disalin; pembatasan server tidak menjadikannya mustahil diambil.
