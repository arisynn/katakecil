# KataKecil — Native Preview 2

Melanjutkan Preview 1 dengan penyelarasan Reader: satuan jarak huruf diperbaiki, jarak paragraf/indentasi memakai layout yang sama untuk pengukuran dan rendering, serta judul mengikuti font bacaan. Pagination dihitung di worker secara berurutan dan dapat dibatalkan ketika layout berubah; posisi tetap menggunakan offset teks.

Panel daftar bab membatasi konten ke setengah ruang jendela, dengan judul/tab di atasnya. Tab memakai ikon dan lensa yang mengikuti drag langsung. Pengaturan baca memakai tiga tab Teks/Layout/Tema dan kontrol lebih rapat. Tema kustom memakai dialog; Comfort defaults meminta konfirmasi dan hanya mereset pengaturan membaca.

Slider memakai track tipis, thumb bulat dan penyelesaian langsung pada release/cancel. Page scrubber memperlihatkan halaman selama digeser. Input notes tetap dikelola di dialog yang sama. Default baru mengikuti web tanpa mereset pilihan pengguna yang sudah tersimpan.

**KataKecil.apk**, versionCode13, package dan penanda tangan sama dengan preview sebelumnya. Pasang tanpa uninstall untuk mempertahankan data native.

QA HP oleh pemilik; hanya kompilasi release dan pemeriksaan artefak pada sesi ini. Coba perubahan font/margin, rotasi, halaman lanjutan paragraf, slider, Contents/Notes, konfirmasi reset, dan keyboard notes.
