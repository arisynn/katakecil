# KataKecil 1.2.9 — Ikon Lembar dan Tema ringkas

**Status:** APK lokal selesai dan terverifikasi. Push dan publikasi GitHub belum berhasil karena autentikasi token ditolak (HTTP 401). Rilis publik terakhir tetap 1.2.8.

APK terbaru memuat empat koleksi ikon: Rounded KataKecil, Lucide, Lentera dan Lembar. Lembar menjadi default untuk perangkat tanpa pilihan valid tersimpan. Pilihan ikon yang sudah disimpan tetap digunakan. Lembar/Lentera memakai outline saat normal dan solid saat ditekan atau dipilih; play, pause dan kutipan Lembar sudah diperbaiki menjadi garis saat normal.

**Glow halaman baca kini di sebelah Kustom**, baik di Tema Pengaturan maupun reader. Layout dipadatkan untuk layar pendek agar toggle terjangkau tanpa scroll pada ukuran yang diuji. Glow tetap mati secara default dan mengikuti intensitas Ambient saat diaktifkan.

Versi **1.2.9 / build 17**, package dan signer Karisyono tetap. Pasang langsung di atas aplikasi yang ada tanpa uninstall untuk mempertahankan data. Splash buku pemulihan 1.2.8 dipertahankan.
