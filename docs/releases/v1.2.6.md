# KataKecil 1.2.6 Stable

Splash baru menampilkan buku sejak layar awal Android, lalu scene buku 3D dan tulisan katakecil dengan ambient aksen. Package **id.karisyono.katakecil**, versionCode **14**, sertifikat Karisyono tetap sama agar APK dapat dipasang sebagai pembaruan.

## Perubahan sejak 1.2.5

- **Splash Android baru:** ikon buku animated vector menjembatani starting window ke scene buku 3D, wordmark huruf bergerak, glow aksen dan tagline. Latar opak sejak frame pertama; splash memudar 200 ms setelah konten siap, tanpa menunggu satu siklus animasi atau menambah durasi minimum. Mode kurangi gerakan menampilkan versi statis.
- Splash khusus startup tetap memakai identitas buku meskipun loading di dalam aplikasi dipilih Classic/Ink flow. Tema dan aksen mengikuti pengaturan aplikasi; warna default native disejajarkan dengan Pearl/charcoal.
- **Ikon & Loading:** pilih seluruh 52 ikon Rounded KataKecil solid/dua nada atau Lucide outline resmi. Pilih Classic wordmark, Turning pages 3D dari HTML pengguna atau Ink flow. Turning pages menjadi default baru untuk preferensi yang belum memiliki pilihan valid; pilihan lama tetap digunakan.
- **Glow halaman baca** di Tema, default mati; saat aktif mengikuti aksen/intensitas Ambient, tanpa mengubah ukuran teks atau posisi baca.

## Pemeriksaan singkat

Build helper web, typecheck/check dan **21 tes terarah** splash/renderer/controller lulus. Chromium memeriksa layar 320×568, 390×844 dan landscape 667×375, terang/gelap, kedua bahasa, layout opak tanpa overflow, reduced motion, exit/cancel/fallback dan pelestarian node reader. Startup aplikasi sebenarnya juga diperiksa dengan bridge native mock: starting window dilepas saat overlay web siap, overlay hilang setelah Library siap, dan jaringan gagal tidak meninggalkan splash.

APK release dibangun dengan **--skip-qa**, kemudian diverifikasi: signature v2/v3, signer yang sama, alignment, package/versionCode, checksum, semua **117 aset web** identik dengan source build, serta resource animated vector ikut terpaket. Tidak menjalankan suite penuh, testReleaseUnitTest/lintRelease penuh, emulator atau HP fisik. Pengujian Chromium/bridge mock tidak membuktikan tampilan starting window OS di perangkat. [Hasil validasi](https://github.com/arisynn/katakecil/blob/main/docs/generated/1.2.6-stable-validation.json).
