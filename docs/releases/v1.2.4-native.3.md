# KataKecil — Native Preview 3

Menyelesaikan tiga tahap penyelarasan native dengan web, setelah Preview 1 (fondasi, Library, Settings) dan Preview 2 (Reader). Tampilan tetap memerlukan penilaian di HP; ini bukan klaim kesamaan piksel pada semua perangkat.

Publisher memakai header dan ruang tepi yang sama dengan Settings, login ringkas dengan tombol lihat kata sandi, serta daftar buku dengan sampul, status dan aksi Update/EPUB. Alur autentikasi dan publikasi tetap menggunakan layanan yang sama.

Color picker memakai cincin hue dan kotak saturasi/kecerahan, input HEX tanpa autofocus, serta tombol Apply tetap terlihat. Tema kustom tetap berupa dialog dengan preview dan pemeriksaan kontras. Label input, About, impor EPUB, penyimpanan, notes dan panel reading tools memakai komponen bersama. Penghapusan EPUB pribadi meminta konfirmasi.

Updater menempatkan aksi di atas changelog yang bergulir. Setelah APK selesai diunduh dan diverifikasi, pengguna menekan Pasang pembaruan. Preview hanya disertakan ketika opsi terkait aktif. Animasi halaman mengikuti pilihan fade/slide/none.

**KataKecil.apk**, versionCode 14, package `id.karisyono.katakecil.nativeapp`, penanda tangan Karisyono sama dengan preview sebelumnya. Pasang di atas preview native tanpa uninstall. Tetap dapat dipasang berdampingan dengan Capacitor; data kedua aplikasi terpisah.

Hanya kompilasi release dan pemeriksaan identitas/tanda tangan/alignment/checksum. Tidak menjalankan QA perangkat, emulator, atau suite pengujian UI. Silakan coba keyboard login/notes/HEX, panel pendek di layar kecil, Publisher, perpindahan halaman, serta alur unduh/pasang updater.
