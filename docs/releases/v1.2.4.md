# KataKecil 1.2.4 Stable

Publisher dan notifikasi toast mengikuti gaya kaca terbaru. Package `id.karisyono.katakecil`, versionCode **12**, memakai sertifikat Karisyono yang sama untuk pembaruan di atas APK sebelumnya.

## Perubahan sejak 1.2.3

- Panel login, pemulihan kata sandi, daftar buku dan editor Publisher memakai permukaan Liquid Glass bersama. Kebeningan, blur, ambient, tema dan aksen mengikuti pengaturan aplikasi.
- Kolom input memakai lapisan transparan di dalam panel; fokus dan tombol tetap terbaca pada tema terang/gelap. Bagian jadwal dan pembaruan bab memiliki judul, serta tombol editor ditata agar muat pada HP.
- Tombol unduh, tampilkan kata sandi dan tautan aksi mendapat respons tekan yang sama dengan kontrol aplikasi. Judul halaman Publisher tetap benar saat preferensi disinkronkan.
- Semua toast aplikasi (backup, impor, salin, error dan lainnya) memakai warna tema, sorotan kaca, blur dan ambient. Lapisan dasar dibatasi minimum 70% agar pesan tetap terbaca, termasuk saat kebeningan maksimum. Perilaku timer, teks dan pengumuman aksesibilitas tetap sama.
- Browser tanpa backdrop blur memakai permukaan solid; animasi menghormati reduced motion. Loading wordmark lama tetap dipertahankan.

## Pemeriksaan singkat

- Build helper web, typecheck, pemeriksaan sintaks/modul dan 18 tes terarah Publisher, kaca dan respons tekan/tab lulus.
- Chromium memakai fixture lokal untuk auth/API, tanpa publikasi ke server produksi: login/password/key/recovery, impor EPUB tamat, update bab bersambung dengan ID/jadwal lama dipertahankan, konfirmasi publikasi, unduhan EPUB dan backup, tema terang/gelap, rentang kaca, reduced motion serta layout HP/landscape/desktop.
- Toast **Backup saved** diperiksa melalui ekspor backup sebenarnya di browser, pada kedua tema.
- APK dibangun dengan `--skip-qa`. Signature v2/v3, sertifikat, alignment, package/versi, checksum dan kesamaan aset web diperiksa. Suite penuh, lint Android dan pengujian HP fisik tidak diulang.
- [Bukti pemeriksaan](https://github.com/arisynn/katakecil/blob/main/docs/generated/1.2.4-stable-validation.json).

## Unduh dan uji di HP

Unduh `KataKecil-1.2.4-Karisyono.apk` dari Assets atau periksa **Pengaturan → Pembaruan aplikasi**. Berkas `.sha256` dan `KataKecil-release-info.json` tersedia untuk pemeriksaan integritas dan revisi source.

1. Pasang sebagai pembaruan; periksa progres, catatan dan EPUB lokal.
2. Buka **Pengaturan → Advanced → Publisher**, masuk, lalu periksa daftar buku dan editor saat keyboard/landscape digunakan.
3. Ubah kebeningan, blur dan ambient; periksa Publisher dalam tema terang dan gelap.
4. Simpan backup dan periksa toast baru. Untuk publikasi berikutnya, periksa target bab/jadwal pada tinjauan sebelum menerapkan perubahan.
