# KataKecil 1.2.0 Stable

Rilis stable sesuai persetujuan pemilik. Android package `id.karisyono.katakecil`, versionCode **8**, dengan sertifikat Karisyono yang sama.

**Masalah yang diketahui:** laporan Play Protect pada 1.1.1 dan 1.1.2-rc.1 belum dinyatakan selesai; klasifikasi Google untuk 1.2.0 belum diverifikasi. Status stable adalah kanal rilis yang disetujui pemilik, bukan sertifikasi malware atau pernyataan bahwa blokir Google sudah diperbaiki. Bila Play Protect memblokir pemasangan, hentikan dan laporkan versinya; jangan melewati atau menonaktifkan pemindaian. [Status pemeriksaan](https://github.com/arisynn/katakecil/blob/main/docs/play-protect-review.md).

## Perubahan

- Sampul EPUB pribadi diambil dari metadata EPUB 2/3 atau halaman cover. Sampul impor lama dipulihkan dari berkas lokal yang sudah tersimpan.
- EPUB dari file manager Android melalui Buka dengan/Bagikan masuk ke pratinjau impor Library pribadi. Impor tetap tersedia di Settings → Advanced; header Library hanya berisi refresh dan pengaturan.
- Parser EPUB lokal lebih adaptif terhadap bab, episode, prolog/epilog, arc bertingkat dan target fragmen daftar isi. Identitas bagian serta progres/anotasi dimigrasikan dengan pencocokan kutipan; hasil ambigu perlu ditinjau.
- Baca cepat RSVP 100–600 kata/menit, ±5 kata, jeda tanda baca/paragraf dan posisi tersimpan. Mode fokus memenuhi halaman, menempatkan huruf penanda tetap di tengah, menyembunyikan kontrol saat berjalan, serta menyediakan fullscreen browser bila didukung.
- Ukuran font RSVP sama untuk seluruh kata dalam satu episode/tampilan, menggantikan perubahan ukuran per kata panjang.
- Sheet Tools dan RSVP lebih ringkas untuk layar HP/landscape.
- **Settings → Advanced → Manage personal EPUBs / Kelola EPUB pribadi:** ganti cover, pulihkan sampul asli atau hapus EPUB lokal. Progres/catatan tetap disimpan untuk impor ulang berkas yang sama. Gambar cover hanya disimpan di perangkat; buku server/Publisher tidak dikelola melalui menu ini.

## Pemeriksaan dan batas

- 34 tes Node terarah lulus, termasuk enam EPUB fixture domain publik, parser/cover, progres/anotasi, updater, Publisher dan pengelolaan buku lokal.
- Build helper web, typecheck dan pemeriksaan modul lulus.
- Chromium mobile 390×844 dengan katalog mock: cover kustom bertahan setelah reload dan pembaruan parser, reset cover, pembatalan/hapus buku, penyimpanan progres/catatan serta identitas impor ulang berhasil. Mode fokus/RSVP sebelumnya diuji dengan fixture sintetis pada portrait/landscape dan tema terang/gelap.
- [Bukti validasi ringkas](https://github.com/arisynn/katakecil/blob/main/docs/generated/1.2.0-stable-validation.json) tersedia di repo.
- APK dibangun dengan `--skip-qa`; signature v2/v3, alignment, SHA-256 dan kecocokan seluruh aset web diverifikasi. Ini bukan QA HP fisik atau pemindaian malware. Tidak menjalankan suite penuh atau uji beban pada sesi rilis.
- Dukungan EPUB berfokus pada novel teks. EPUB ber-DRM, gambar saja/fixed layout, tabel dan footnote interaktif masih memiliki batas. Ukuran impor EPUB maksimal 30 MB.
- Tidak ada deployment Supabase atau perubahan naskah/jadwal server. Pengiriman buku online tetap memakai protokol episode yang sudah tersedia.

## Berkas dan pemasangan

Unduh `KataKecil-1.2.0-Karisyono.apk` dari Assets. Berkas `.sha256` dan `KataKecil-release-info.json` tersedia untuk pemeriksaan integritas dan provenance source.

Simpan backup sebelum memperbarui. Jika Android mengizinkan pemasangan, APK dengan package dan signer yang sama dapat dipasang di atas rilis Karisyono sebelumnya tanpa uninstall. Penyimpanan web dan APK terpisah; backup metadata tidak membawa berkas EPUB pribadi.
