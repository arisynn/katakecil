# KataKecil 1.1.1 Official

**Peringatan (5 November 2026):** pemilik melaporkan Play Protect memblokir pemasangan versi ini. Penyebab belum diketahui; jangan melewati Play Protect untuk memasangnya. Pemeriksaan tanda tangan/checksum bukan bukti bebas malware. [Status pemeriksaan](../play-protect-review.md).

- Logo launcher memakai PNG asli dengan ruang aman; tidak lagi memakai vektor kutip yang membesar/terpotong.
- Splash memakai animasi loading KataKecil yang sudah ada. Jika melanjutkan bacaan, loading berakhir setelah episode, font dan pagination siap ditampilkan. Jika membuka Library, katalog dan sampul pilihan disiapkan dahulu. Kegagalan jaringan tetap menampilkan error, bukan menunggu selamanya.
- Tema System Android membaca status OS secara langsung dan mengikuti perubahan saat aplikasi aktif atau kembali dibuka.
- Error Library dipusatkan. Panel updater lebih pendek: tombol unduh/pasang tetap di atas, changelog bergulir di bawah.
- Loading pagination dipertahankan saat resize, rotasi, fullscreen dan perubahan font; posisi bacaan dipulihkan sebelum indikator hilang.
- Izin origin Reader diperbarui untuk URL preview yang terverifikasi dari deployment repo. Tidak membuka wildcard Vercel, arsip sumber atau konten belum terbit.

Petunjuk historis pemasangan: **KataKecil-1.1.1-Karisyono.apk** mendukung pembaruan di atas versi lama tanpa uninstall. Pemasangan versi ini ditunda selama laporan Play Protect belum terjawab. Package dan signer Karisyono tetap; versionCode5. Perubahan UI updater berlaku setelah APK baru terpasang.

QA tampilan/perangkat ditangani pengguna. Sesi rilis tidak menjalankan ulang suite/browser/HP; hanya build serta verifikasi tanda tangan, alignment, checksum dan pemasangan. Tidak ada migrasi database atau perubahan buku/jadwal.
