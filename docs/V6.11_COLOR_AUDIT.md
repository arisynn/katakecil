# Audit warna frontend V6.11

**Palet resmi**: Arctic Blue (`#F4F8FD`, `#FFFFFF`, `#E9F2FC`, `#172C48`, `#506781`, `#235DB4`, `#D5E3F2`) dan Midnight Sapphire (`#081425`, `#10243D`, `#173251`, `#EFF6FF`, `#B2C5DA`, `#9BC9FF`, `#294665`). Token global didefinisikan di `src/design/v67-sapphire-polish.css`.

- Public: kartu, navigasi, detail, dan daftar bab sudah mengonsumsi token semantik V6.7. Tidak dirombak di V6.11.
- Studio: komponen V6.9 menggunakan `--st-*` dari `--kk-*`; indikator jadwal yang sebelumnya berwarna hijau/oranye langsung kini memakai aksen biru.
- Reader: halaman, judul, kontrol, daftar isi, pengaturan, recovery, seleksi, dan loading diselaraskan lewat `v611-immersive-reader.css` setelah CSS historis.
- Boot: HTML awal hanya memakai dua varian Sapphire dan membaca preferensi global sebelum React.
- Audit statis: 30 komponen `.tsx/.jsx` tanpa literal hexadecimal, namun 1.200 literal di CSS historis masih ada dan memerlukan inspeksi cascade visual.

**Perlu QA runtime:** status sukses/gagal tetap boleh menggunakan warna semantik berbeda dari biru, selama kontrasnya sesuai. Jangan mengganti semua warna dengan biru secara buta. Lakukan inspeksi pada semua halaman dalam kedua tema, termasuk keadaan loading, empty, disabled, hover, focus, dialog, dan error.
